# AegisMail

An AI-driven browser extension tailored for Gmail that classifies email threats using a machine learning backend.

## Problem Statement
Users struggle to identify sophisticated phishing emails and targeted threats in their daily communications, leading to compromised accounts and data breaches. Standard spam filters often miss nuanced, text-based social engineering attacks, leaving users to rely on their own limited security knowledge, which wastes time and causes anxiety when opening emails.
